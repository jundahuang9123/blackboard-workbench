Run your own data

Upload a table and one or more ontologies. Reference mappings are optional; without them, the run has no benchmark score.

The first row must contain unique column names. All columns are mapped using the first selected example rows. Supports UTF-8 CSV and XLSX; export formulas as values.

Up to five ontologies, with distinct prefixes for distinct namespaces. Reference answers are used only to evaluate the output.

Reference mapping format

Use exact column names and full ontology IRIs or declared prefixes. You may provide references for only some columns; the benchmark then covers those columns only.

{
  "employeeName": {"class": "ex:Employee", "property": "ex:name"},
  "salary": {"class": "ex:Employee", "property": "ex:salary"}
}

Sebastian’s existing JSON format with prefix and mappings is also accepted.
