# Attribution

This workbench complements Sebastian Chmielewski et al.'s SAST-Blackboard at <https://github.com/U0iS112/654321>. It reads that project's output and, when configured, calls its original pipeline. No upstream source files are copied here.

Paper: Chmielewski, Schindler, Fernandes, Meisen and Pomp, “Signal-Aware Semantic Typing of Tables via Blackboard-Orchestrated Large Language Models,” SDS 2026.

The built-in synthetic example is for interface demonstration only.
